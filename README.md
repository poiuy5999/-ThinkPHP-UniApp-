# 洗车小程序系统ThinkPHP+UniApp 

源码地址：ym7k.com/17823/洗车小程序系统ThinkPHP+UniApp 

这套洗车服务小程序后端基于 ThinkPHP 框架开发，前端采用 UniApp，一套代码可编译微信小程序、H5、APP，是面向洗车门店、连锁汽修店的 O2O 会员预约系统，支持到店洗车、上门洗车，自带会员次卡、订单核销、技师派单等全套能力，私有化部署，适合中小洗车店数字化改造。

多台车辆档案，查看附近门店、服务项目，包含普洗、精洗、内饰清洁、打蜡等套餐。支持即时下单和预约下单，用户自主选择时间段，系统自动锁定工位，避免到店排队。会员体系是核心，后台可以配置储值赠送、次卡、月卡、年卡，下单时余额、次卡、优惠券自动抵扣，消费记录、剩余次数、到期提醒在个人中心清晰展示。订单完成后可以上传施工照片、评价，也可发起售后反馈。

技师端同样基于 UniApp 开发，支持小程序或者独立 APP 接单，系统提供派单、抢单两种模式。接单后导航前往服务地点，打卡签到、上传施工前后对比图，完工提交结算。后台可设置技师抽成比例，收入明细、提现流水一目了然，方便门店核算绩效。

缓存订单、会员、工位数据，提升访问速度。管理员维护门店信息、服务项目、价格套餐，管理技师账号、审核提现申请。订单管理模块统一查看全部订单，支持扫码核销；数据看板统计营收、复购率、技师绩效，订单记录可导出 Excel 报表用于对账。多门店版本支持分店独立管理，总部统一管控套餐和资金，适合连锁门店。权限分级清晰，店长、前台、技师权限隔离，数据互不干扰。

部署环境推荐 PHP7.4~8.1、MySQL5.7、Nginx，配置 HTTPS 域名。部署流程简单，上传源码、导入 SQL、修改数据库配置，填写小程序 AppID 即可对接。源码开放，二次开发便捷，可以拓展分销推广、配件商城、积分兑换、订阅消息通知，订单状态变更自动推送提醒给车主和技师。

运营层面，上门洗车可以设置电子围栏，限定服务半径；预约时段精细化管控，防止超约。合规方面做好隐私保护，车主信息仅用于服务，定期备份数据库。这套系统依托 ThinkPHP 成熟稳定的生态，开发门槛低，UniApp 多端适配灵活，门店能够自主掌握会员和订单数据，摆脱第三方 SaaS 平台抽成，是洗车门店线上引流、会员留存、流程管理的实用方案。
